# Gemma Garden Guardian HyperFrames Production Breakdown

## Style Block

Use the project video identity from `demo_video/design.md`: background `#07100b`, foreground `#f7fbf6`, muted text `#b9c8bc`, primary accent `#62d27e`, secondary accent `#7dd3fc`, caution accent `#ffd166`, tomato accent `#f25f4c`, and soil accent `#8b6548`. Typography uses Inter or system sans-serif, with heavy headlines and calm readable body copy.

## Rhythm Declaration

`hook-breathe-demo-build-impact-close`

The video is 180 seconds. It starts with a clear problem hook, breathes into the vision, holds a long replaceable demo section, explains the technical flow, lands the social impact, and closes with the project message.

## Global Rules

- Use `docs/video_script.md` as the narration source.
- Keep the 0:45-1:40 demo section replaceable with real Streamlit screen recording.
- Use safe wording: visible signs, possible risks, uncertainty, checks, and local expert confirmation.
- Avoid pesticide instructions, diagnosis language, fake logos, and overclaiming.
- Maintain a practical agricultural feel using real crop imagery from `assets/thumbnail.png` and `sample_data/images/tomato_web/`.

## Scene Beats

### 0:00-0:20 Problem

Concept: Introduce the challenge of interpreting garden changes. Use the project thumbnail as a cinematic field backdrop and layer problem cards for yellow leaves, dry soil, weeds, limited expertise, and safety.

Animation choreography: Slow image push, cards already placed as stable visual anchors, subtitle hold for narration.

Transition out: Direct handoff to the vision scene.

### 0:20-0:45 Vision

Concept: Show the project as a practical AI field assistant. The phone-like crop view with markers and a scan line makes multimodal analysis understandable without overclaiming.

Animation choreography: Phone panel holds to the right, scan line repeats finitely, markers stay visible as observation hints.

Transition out: Direct handoff to app demo placeholder.

### 0:45-1:40 Demo Placeholder

Concept: Represent the Streamlit demo until real footage is recorded. The screen shows upload, crop type, notes, analyze action, dashboard, todos, risk score, JSON validation, history, and report.

Animation choreography: Stable UI frame for readability. Add a visible placeholder ribbon so it is obvious this segment should be swapped later.

Transition out: Move from product proof to technical workflow.

### 1:40-2:20 Technical Explanation

Concept: Explain the system architecture: User -> Streamlit -> Gemma 4 -> JSON -> Tool Layer -> Dashboard. Support it with five technical milestones.

Animation choreography: Flow nodes and milestone cards remain readable for voiceover pacing.

Transition out: Direct handoff into impact.

### 2:20-2:45 Impact

Concept: Make the benefit concrete for home gardeners, small-scale growers, community gardens, elderly growers, and people with limited expert access.

Animation choreography: Four impact panels show clearer photos, earlier checks, safer language, and practical action.

Transition out: Calm closing.

### 2:45-3:00 Closing

Concept: End on the core message: AI should help growers observe, learn, and act with confidence.

Animation choreography: Large project statement over the garden image with a compact MVP proof note.

## Negative Prompt

Avoid medical-style certainty, definitive plant disease diagnosis, pesticide recommendations, fear-based visuals, fake brand marks, fake UI text beyond the designed mock dashboard, and overly glossy corporate stock imagery.
