# Gemma Garden Guardian Handoff Files

This ZIP contains Markdown handoff files for developing the Kaggle "The Gemma 4 Good Hackathon" project with Codex.

Recommended use:

1. Create or open your `gemma-garden-guardian` repository.
2. Copy `AGENTS.md` to the repository root.
3. Copy the `docs/` directory into the repository.
4. Start Codex in the repository root.
5. Ask Codex:

```text
Please read AGENTS.md and docs/HANDOFF.md first.
Then implement Phase 1 and Phase 2 from docs/TASKS.md.
Keep the app runnable and start with mock mode.
```
